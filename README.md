# BEACON 🌱

### Behavioral and Emotional Awareness for Connection, Observation and Nurturing

BEACON is a student wellness platform designed to encourage emotional awareness and healthy self-care habits through daily check-ins, journaling, and interactive wellness activities.

## Features

- **Daily Mood Check-ins:** Record and reflect on daily moods.
- **Expressive Journaling:** A space to express thoughts and feelings.
- **Wellness Garden:** A gamified experience that encourages consistent self-care.
- **Self-Care Activities:** Explore breathing, drawing, music, and dance.
- **Experimental AI-Assisted Journal Analysis:** A separate machine-learning component exploring text classification for mental-health-related categories.

## Tech Stack

- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Machine Learning:** Python, PyTorch, Hugging Face Transformers, BERT
- **Development:** Git and GitHub

## Project Structure

- `home.html` — Main landing page
- `checkin.html` — Daily mood check-in
- `garden.html` — Wellness garden
- `diary.html` — Journaling interface
- `profile.html` — User profile
- `tips.html` — Self-care resources
- `help.html` — Help and support
- `evaluate.py` — Experimental model evaluation script

The repository also includes individual HTML pages for wellness activities.

## Getting Started

1. Clone this repository or download the project files.
2. Open `home.html` in your browser.
3. Navigate through the available wellness features.

The frontend can be explored directly in a browser. The machine-learning evaluation script requires separately configured model weights, a compatible test dataset, and the necessary Python dependencies. These resources are not included in this repository.

## Important Note

BEACON is a student project exploring digital wellness support. Its machine-learning component is experimental and is not a substitute for professional mental-health care, diagnosis, or treatment.

## Project Status

Developed as a student project. The frontend can be explored locally, while the experimental machine-learning component requires additional setup.
