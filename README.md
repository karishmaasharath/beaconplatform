# BEACON 🌱
### Behavioral and Emotional Awareness for Connection, Observation and Nurturing

BEACON is an AI-assisted student wellness platform designed to encourage emotional awareness and healthy self-care habits through daily check-ins, journaling, and interactive wellness activities.

## Features

- **Daily Mood Check-ins:** Record and reflect on daily moods.
- **Expressive Journaling:** A space for users to express their thoughts and feelings.
- **Wellness Garden:** A gamified experience that encourages consistent self-care.
- **Self-Care Activities:** Explore activities such as breathing, drawing, music, and dance.
- **AI-Assisted Journal Analysis:** A machine-learning component exploring text classification for mental-health-related categories.

## Tech Stack

- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Machine Learning:** Python, PyTorch, Hugging Face Transformers, BERT
- **Development:** Git and GitHub

## Running the Frontend

1. Clone this repository.
2. Open `home.html` in your browser.
3. Navigate through the available wellness features.

The machine-learning evaluation component requires separate model setup, dependencies, and a compatible test dataset.

## Project Structure

- `home.html` — Main landing page
- `checkin.html` — Daily mood check-in
- `garden.html` — Wellness garden
- `diary.html` — Journaling interface
- `help.html` — Help and support page
- `evaluate.py` — Model evaluation script
- `bert_journal_model/` — Model configuration and tokenizer files

## Getting Started

1. Clone this repository.
2. Open `home.html` in a browser to explore the frontend.
3. For machine-learning evaluation, configure the model path and provide the required test dataset and Python dependencies.

## Important Note

BEACON is a student project exploring digital wellness support. Its machine-learning component is experimental and is not a substitute for professional mental-health care or diagnosis.
